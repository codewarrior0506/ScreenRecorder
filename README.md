# 🎥 ScreenRecorder

A lightweight and intuitive web-based screen recording application built with HTML, CSS, and JavaScript. Easily capture your screen directly from your browser—no installations or extensions required.

---

## 🚀 Features

- ✅ Record full screen or specific application window
- 🎤 Option to record with or without microphone audio
- ⏱️ Simple and responsive user interface
- 💾 Download recorded videos in `.webm` format
- 🔒 No third-party dependencies or server-side code — 100% client-side

---

## 🌐 Live Demo

Try it now: [ https://screen-recorder-ten-gamma.vercel.app/ ]


---

## 🛠️ Technologies Used

- **HTML5** – Semantic structure
- **CSS3** – Custom styling and responsive layout
- **JavaScript** – Core logic using the MediaRecorder and getDisplayMedia APIs

---

## 📸 How It Works

1. Click **Start Recording** to choose what to share (screen, window, or tab).
2. Use **Stop Recording** to end the session.
3. Preview and download your video instantly.
